# Service photos

Drop real photos of your work here to replace the illustrations on the website.

Name each file after the service or sub-service slug in `src/content/site.ts`:

| File | Shows on |
|---|---|
| `signage.jpg` | the "Signage & lightboxes" service |
| `signage--lightboxes.jpg` | its "LED lightboxes" sub-service |
| `vehicle-branding--fleet.jpg` | "Fleet branding" under vehicle branding |

`.jpg`, `.jpeg`, `.png` and `.webp` all work. Landscape photos (4:3) look best; any size is fine —
they are resized and compressed automatically when the site is built.
